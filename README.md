# Aura Play - Web App Version

A modern, neon-aesthetic music player built as a web application.

## Setup & Running

### Prerequisites
- Node.js (v16 or higher)
- npm

### Installation

1. Clone or navigate to the project:
```bash
cd Aura-PLay
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open in your browser:
```
http://localhost:5173
```

## Features

✨ **Stunning Neon Design** — Dark theme with glowing cyan and purple accents

🎵 **Audio Playback** — Support for MP3, WAV, OGG, FLAC, M4A

⏯️ **Full Controls** — Play, pause, skip, previous, volume control

📊 **Progress Bar** — See playback progress and seek to any point

📂 **File Management** — Load multiple audio files at once

## How to Use

1. Click "🎵 Choose Audio File" on the main screen
2. Select one or multiple audio files from your computer
3. Click a file to play it
4. Use the controls to play, pause, skip tracks
5. Adjust volume with the slider

## Build for Production

```bash
npm run build
```

Output will be in the `dist` folder.

## Technologies

- Vite (fast build tool)
- HTML5 Audio API
- Modern CSS with gradients and animations
